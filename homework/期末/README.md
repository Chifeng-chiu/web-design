## 作業 01 — 個人網站與相簿：靜態網頁的結構思維

這個作業的核心在於理解「資訊架構」如何影響使用者的瀏覽體驗。index.html 是一張個人名片頁面，透過卡片元件將自我介紹、興趣分類（運動、攝影、旅遊）組合成一個視覺層次清晰的入口；而 gallery.html 則實作了「以參數驅動內容」的模式 — 透過 URL query string (`?category= sports`) 決定要載入哪個分類的圖片，這背後的概念其實就是現代前端路由的雛型。CSS 方面採用了玻璃擬態（glassmorphism）與漸層背景，讓頁面在沒有框架的前提下依然擁有接近設計工具的視覺品質。這個作業真正要學的不是語法，而是「如何用 HTML 標籤的層級去對應內容的層級，並用 CSS 賦予它情緒」。

## 作業 02 — 生活習慣問卷：表單的本質是資料的通道

表單是網頁與使用者之間最直接的溝通工具。這個作業的價值不在於欄位多寡，而在於它教會了你「表單的每一次提交都是一條資料的產生命令」。從文字輸入、單選鈕、複選框到文字區塊，每種輸入類型都有其適用的情境 — 單選代表排他性選擇，複選代表並列性愛好，文字區則承載非結構化的意見。驗證機制則是表單的守門員，確保資料在離開客戶端之前已經符合基本規範。這個作業背後的哲學是：前端表單不是單純的 UI 元件集合，而是使用者意圖轉換為結構化資料的第一道關卡。

## 作業 03 — Node.js Hello World：跳脫瀏覽器的 JavaScript

這支看似簡單的程式碼，其實代表了一個觀念上的斷裂：JavaScript 不再只能活在瀏覽器的 `<script>` 標籤裡。當你在終端機執行 `node hello.js` 並看到 "Hello, World!" 印出來的那一刻，你實際上已經體驗了「執行環境切換」這個開發者必備的抽象理解能力。Node.js 的核心原理是事件驅動的非阻塞 I/O 模型，這支 hello world 雖然沒有展現任何非同步操作，但它是你通往伺服器端開發的第一塊基石 — 理解在你寫的程式碼與作業系統之間，有一個稱為「執行期環境」的中介層存在。

## 作業 04 — JavaScript 十題練習：語言特性與程式思維的交叉訓練

這不是單純的語法練習，而是一種「刻意練習」的學習策略。每一題都瞄準了一個 JavaScript 的核心機制：

- **偶數判斷**（`%`）教你「模運算」這個在演算法中廣泛使用的基本工具
- **陣列總和**（`reduce()`）讓你理解「累積器」這個函數式編程的核心模式
- **次方計算**（`Math.log2` / `Math.ceil`）展示了數學函式如何與商業邏輯結合
- **物件存取**（dot vs bracket notation）教會你 JavaScript 中「屬性即字串」的本質
- **JSON 操作**揭示了前後端資料交換的通用格式 — 這在後續的作業 05 中會反覆出現
- **購物車模擬**則是狀態管理的最小模型：商品的新增、刪除、數量變更、折扣計算，這些邏輯在每一個電子商務網站中都以相同的方式運作

這個作業真正的目的是建立「將問題拆解為程式邏輯」的直覺。

## 作業 05 — 部落格系統：全端應用的最小可行模型

這是整學期最重要的轉折點。部落格系統涵蓋了現代網頁應用程式的所有核心層面：

**路由設計** — Express 的路由系統本質上就是一個「請求和處理器的配對表」。`app.get('/post/:id', ...)` 背後的概念是 URL 參數化，而同一個 route 搭配不同的 HTTP method（GET/POST）則體現了 RESTful 的設計哲學。

**模板引擎（EJS）** — 在伺服器端將資料嵌入 HTML，代表的是傳統的多頁面應用模式。每一次請求都經過「路由 → 資料查詢 → 模板渲染 → 回應 HTML」的完整循環，這就是 MVC 架構的具體實踐。

**認證機制** — bcrypt 雜湊與 express-session 的結合，展示了「如何在不信任的網路環境中建立信任」。密碼不該以明文儲存，session 需要 secret 簽名，這些都是安全性的基本素養。

**資料庫操作** — SQLite 的嵌入特性讓開發階段不需要額外安裝資料庫伺服器，但 CRUD 的操作邏輯與 PostgreSQL 或 MySQL 完全一致。

這個作業教會你的是：一個全端應用程式從來不是單一技術的展示，而是「路由 + 資料庫 + 認證 + 視圖層」四者如何協作的問題。

## 作業 06 — JS 函式學習中心：JavaScript 中最被低估的力量

函式在 JavaScript 中不是次等公民 — 它就是公民。這個作業的 quiz 模式與 study 模式分別對應了「被動辨識」與「主動建構」兩種學習層次。

核心原理包括：

**閉包（Closure）** — 函式能夠「記住」它被建立時的環境，即使那個環境已經消失。這是 JavaScript 中最違反直覺卻也最強大的特性，它讓工廠函式、私有變數、部分應用等模式成為可能。

**IIFE** — 立即被調用的函式表達式，解決了「變數汙染」這個在模組系統出現前的大問題。每一次 `(function(){ ... })()` 都是一個隔離的宇宙。

**高階函式** — 接受函式作為參數或回傳函式的函式。`Array.prototype.map`、`filter`、`reduce` 都是高階函式，它們讓資料轉換變得宣告式而非命令式。

**回呼（Callback）** — JavaScript 非同步操作的基石。雖然現代 JavaScript 已經有 Promise 和 async/await，但理解 callback 等於理解這整個非同步機制的起源。

這個作業不是教你怎麼寫函式，而是教你「為什麼函式在 JavaScript 中無所不在」的設計哲學。

## 作業 07 — 後端模式 JS 挑戰：從前端思維到後端思維的轉換

這份作業可以視為作業 05 的前置補強。它的目標很明確：讓你用熟悉的 JavaScript 語法，去熟悉 Node.js / Express 後端開發中會反覆出現的模式。

**解構賦值** — `const { title, content } = req.body` 不僅是語法糖，它體現了「關注點分離」：你只取你需要的東西。

**Error-First Callback** — Node.js 的非正式標準。`if (err) return callback(err)` 這個模式看似囉嗦，但它強迫開發者「先處理錯誤，再處理資料」，這是穩健系統的第一原則。

**模板字面值中的邏輯運算** — `` `...${value || '預設值'}...` `` 展示了渲染層的防禦性編程。

**模擬資料庫查詢** — 用 setTimeout 模擬非同步 DB 查詢，讓你隔離理解「回呼的流程控制」而不需要真的連接資料庫。

這個作業的真正價值在於：它為作業 05 中那些看似陌生的 Express 程式碼，提供了語義上的「預習」。

## 期中專案 — StockBoard 股市論壇：全端架構的完整實踐

這是整學期最具挑戰性的作品，因為它要求你同時管理多個技術層面的協作。

**FastAPI 的非同步基因** — 不同於 Express 的事件循環，Python 的 async/await 提供了另一種並行模型。`async def` 讓路由函式在等待 I/O（如資料庫查詢、外部 API 請求）時可以讓出事件迴圈給其他請求處理。

**ORM 與資料庫抽象** — SQLAlchemy 將資料表映射為 Python 物件，`User`、`Post`、`Comment`、`TradeRecord` 之間的關聯（foreign key、relationship）反映了真實世界中的實體關係。你不需要寫 SQL 就能操作資料庫，但你必須理解 SQL 才能理解 ORM 為什麼那樣設計。

**外部 API 整合** — yfinance 套件讓你的應用程式能夠獲取 Yahoo Finance 的即時股價與歷史資料。這不僅是 API 呼叫的技術問題，更涉及「如何處理外部服務的延遲與失敗」的錯誤處理策略。

**SPA 架構** — 前端全部用 Vanilla JS 實作單頁應用，沒有框架，卻實作了路由切換、狀態管理、API 呼叫等功能。這讓你親身體驗到框架其實是為你解決了哪些問題。

**Chart.js 圖表** — 將歷史股價資料視覺化為折線圖，這是資料從「數字」轉變為「洞察」的關鍵一步。

這個專案的核心原理總結為一句話：真正的全端開發不是把前端和後端寫在一起，而是讓它們透過 API 合約進行鬆散耦合的通訊。

## 部署方式

### GitHub Pages

1. 在 GitHub Repo 首頁點選 **Settings → Pages**
2. **Source** 選擇 **Deploy from a branch**
3. **Branch** 選擇 `main`，資料夾選擇 `/ (root)`
4. 網址即為 `https://<你的帳號>.github.io/<repo名稱>/`

### 本地瀏覽

直接用瀏覽器打開 `homework/期末/index.html` 即可。
