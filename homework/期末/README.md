# 期末作業 — 作品集入口網站

一學期下來的所有作品，整合成一個漂亮的卡片式入口網站。

## 部署方式

### GitHub Pages（推薦）

1. 在 GitHub Repo 首頁點選 **Settings → Pages**
2. **Source** 選擇 **Deploy from a branch**
3. **Branch** 選擇 `main`，資料夾選擇 `/ (root)`
4. 網址即為 `https://<你的帳號>.github.io/<repo名稱>/`
5. 若要直接從 `homework/期末/` 部署，可在 Pages 設定中選擇 `homework/期末` 資料夾

### 本地瀏覽

直接用瀏覽器打開 `index.html` 即可（部分絕對路徑可能需要調整）。
