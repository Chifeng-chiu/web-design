    🚀Node.js Hello World
    作業 03
    第一個 Node.js 程式，理解 JavaScript 在伺服器端的執行環境。
    JavaScript
    Node.js
    node hello.js
    █

    觀念上的斷裂：JavaScript 不再只活在瀏覽器的 <script> 標籤裡，執行 node hello.js 代表「執行環境切換」這個關鍵能力。

    核心原理：Node.js 採用事件驅動的非阻塞 I/O 模型，奠定了理解伺服器端開發的基礎。

    學習重點：理解在程式碼與作業系統之間，存在一個稱為「執行期環境」的中介層。

    📝部落格系統
    作業 05
    完整部落格平台：用戶註冊／登入、文章 CRUD、分類篩選。Express + SQLite + EJS。
    Node.js
    ExpressSQLiteEJSbcrypt
    前往 ↗

    路由設計：Express 路由本質是「請求與處理器的配對表」，app.get('/post/:id') 體現 RESTful 設計哲學。

    MVC 架構：EJS 模板引擎讓每次請求走完「路由 → 資料查詢 → 模板渲染 → 回應 HTML」的完整循環。

    認證機制：bcrypt 雜湊 + express-session，密碼不以明文儲存。

    學習重點：全端應用是「路由 + 資料庫 + 認證 + 視圖層」四者協作的問題。

    ⚡JS 函式學習中心
    作業 06
    雙模式函式學習工具：涵蓋箭頭函式、閉包、IIFE、高階函式等核心概念。
    JavaScript
    HTML5CSS3Vanilla JS
    前往 ↗

    閉包（Closure）：函式能「記住」它被建立時的環境，讓工廠函式、私有變數等模式成為可能。

    IIFE：(function(){ ... })() 立即執行，建立隔離作用域。

    高階函式：map、filter、reduce 讓資料轉換從命令式變成宣告式。

    學習重點：理解為什麼函式在 JavaScript 中「無所不在」的設計哲學。

    🔧後端模式 JS 挑戰
    作業 07
    聚焦 Express / Node.js 後端開發模式的 JavaScript 練習。
    JavaScript
    Node.jsExpressCallback
    前往 ↗

    解構賦值：const { title, content } = req.body 體現「關注點分離」，只取需要的東西。

    Error-First Callback：if (err) return callback(err)，強迫先處理錯誤再處理資料。

    模擬資料庫查詢：用 setTimeout 模擬非同步 DB，隔離理解回呼流程控制。

    學習重點：為作業 05 的 Express 程式碼提供語義上的「預習」。

    📈StockBoard 股市論壇
    期中專案
    完整股票討論平台：用戶認證、發文留言、即時股價查詢。
    Python
    FastAPISQLAlchemyyfinanceChart.js
    前往 ↗

    FastAPI 非同步基因：async def 讓路由在等待 I/O 時讓出事件迴圈，提供高效能並行處理。

    ORM 抽象：SQLAlchemy 將資料表映射為 Python 物件，foreign key 關聯反映真實世界的實體關係。

    外部 API 整合：yfinance 獲取 Yahoo Finance 即時股價，涉及外部服務延遲與失敗的錯誤處理策略。

    學習重點：真正的全端開發是讓前後端透過 API 合約進行鬆散耦合的通訊。
