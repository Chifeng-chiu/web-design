## 01 — 判斷奇偶 (Even / Odd)

**語法**
```js
function isEven(n) { return n % 2 === 0; }
```
- 使用**餘數運算子 `%`**：`n % 2` 若為 `0` 表示偶數，否則為奇數。
- `isEven(7)` → `false`

**功能**
輸入任意整數，點擊判斷後顯示該數字為奇數或偶數。

**測試結果**
| 輸入 | 預期 | 實際 |
|------|------|------|
| 7 | 奇數 | 奇數 |
| 12 | 偶數 | 偶數 |
| 0 | 偶數 | 偶數 |
| -3 | 奇數 | 奇數 |

## 02 — 陣列求和 (Array Sum)

**語法**
```js
const sum = arr => arr.reduce((a, b) => a + b, 0);
```
- `reduce(callback, initialValue)` 將陣列逐元素歸納為單一值。
- `arr.reduce((a, b) => a + b, 0)` 從 0 開始，將每個元素累加。

**功能**
輸入逗號分隔的數字，計算所有數字的總和。

**測試結果**
| 輸入 | 預期 | 實際 |
|------|------|------|
| 1,2,3,4,5 | 15 | 15 |
| 10,20,30 | 60 | 60 |
| -1,5,3 | 7 | 7 |

## 03 — 尋找大於目標的最小 2 次方 (Next Power of 2)

**語法**
```js
function nextPow2(n) { return Math.pow(2, Math.ceil(Math.log2(n))); }
```
- `Math.log2(n)` 取得以 2 為底的對數。
- `Math.ceil()` 無條件進位，確保結果不小於 n。
- `Math.pow(2, k)` 計算 2^k。

**功能**
給定正整數 n，找出大於 n 的最小 2 的次方數。

**測試結果**
| 輸入 | 預期 (2^k) | 實際 |
|------|------------|------|
| 50 | 64 (2^6) | 64 |
| 1 | 1 (2^0) | 1 |
| 1000 | 1024 (2^10) | 1024 |
| 7 | 8 (2^3) | 8 |

## 04 — 物件屬性讀取 (Object Property Access)

**語法**
```js
user.name      // 點記法 (dot notation)
user["name"]   // 括號記法 (bracket notation)
```
- 點記法簡潔直觀，但屬性名稱必須是合法識別字。
- 括號記法支援字串變數，適合動態讀取。

**功能**
從下拉選單選擇屬性名稱 (`name` / `age` / `city` / `job`)，讀取 `user` 物件的對應值並顯示類型。

**測試結果**
```js
const user = { name: 'Alice', age: 28, city: '台北', job: '工程師' };
```
| 選擇屬性 | 輸出 |
|----------|------|
| name | Alice (類型: string) |
| age | 28 (類型: number) |
| city | 台北 (類型: string) |
| job | 工程師 (類型: string) |

## 05 — JSON 解析與字串化 (JSON Parse & Stringify)

**語法**
```js
JSON.parse(str)        // 字串 → 物件
JSON.stringify(obj)    // 物件 → 字串
```
- `JSON.parse()` 將 JSON 格式字串轉為 JavaScript 物件。
- `JSON.stringify(obj, null, 2)` 將物件轉為格式化 JSON 字串（第二參數為 replacer，第三參數為縮排空格數）。

**功能**
- **解析**：將 `'{"name":"Bob","age":25,"skills":["JS","Python","SQL"]}'` 轉為物件並顯示各屬性。
- **字串化**：將 `{ product: '滑鼠', price: 350, stock: true }` 轉為格式化 JSON 字串。

**測試結果**
| 操作 | 結果 |
|------|------|
| 解析 JSON | name: Bob, age: 25, skills: [JS, Python, SQL] |
| 字串化物件 | `{\n  "product": "滑鼠",\n  "price": 350,\n  "stock": true\n}` |

## 06 — 陣列過濾 (Array Filter)

**語法**
```js
arr.filter(n => n > 10)
```
- `filter(callback)` 回傳一個新陣列，包含所有通過測試的元素。
- 回呼函式 `n => n > 10` 對每個元素判斷是否大於閾值。

**功能**
輸入逗號分隔的數字陣列與閾值，篩選出所有大於閾值的元素，並顯示篩選比例。

**測試結果**
| 原始陣列 | 閾值 | 結果 |
|----------|------|------|
| 3,15,8,22,1,17,6,30 | 10 | [15, 22, 17, 30] (4/8 個) |
| 1,2,3,4,5 | 3 | [4, 5] (2/5 個) |
| 100,200 | 50 | [100, 200] (2/2 個) |

## 07 — 字母頻率統計 (Character Frequency)

**語法**
```js
const freq = {};
for (const ch of str) {
  freq[ch] = (freq[ch] || 0) + 1;
}
```
- `for...of` 逐一走訪字串中的每個字元。
- `(freq[ch] || 0)` 若 `freq[ch]` 不存在則使用 0，實現計數器累加。

**功能**
輸入一段文字，統計每個字元出現的次數（排除空白），並以長條圖視覺化顯示（依頻率由高到低排序）。

**測試結果**
| 輸入 | 輸出範例 |
|------|----------|
| hello world | 'l': 3 ████████████████████, 'o': 2 ██████████████, 'h': 1 ███████, 'e': 1 ███████, 'w': 1 ███████, 'r': 1 ███████, 'd': 1 ███████ |

## 08 — 陣列反轉（手動演算法版）(Array Reverse — Manual)

**語法**
```js
for (let i = 0; i < n / 2; i++) {
  [arr[i], arr[n - 1 - i]] = [arr[n - 1 - i], arr[i]];
}
```
- **雙指針原地交換**：`i` 從左端、`n-1-i` 從右端向中間逼近。
- 使用 **解構賦值** `[a, b] = [b, a]` 交換兩元素，無需暫存變數。
- 只走訪陣列前半 (`n/2`)，時間複雜度 O(n)，空間複雜度 O(1)。

**功能**
輸入逗號分隔的陣列，使用手動演算法（非 `Array.prototype.reverse()`）反轉元素順序。

**測試結果**
| 輸入 | 原始 | 反轉後 |
|------|------|--------|
| A,B,C,D,E | [A, B, C, D, E] | [E, D, C, B, A] |
| 1,2,3,4 | [1, 2, 3, 4] | [4, 3, 2, 1] |
| apple,banana | [apple, banana] | [banana, apple] |

## 09 — JSON 物件陣列尋找最高分 (Find Top Score)

**語法**
```js
students.reduce((max, s) => s.score > max.score ? s : max)
```
- `reduce` 逐一比較每個學生的 `score`，保留分數較高的物件。
- 初始值即為陣列第一個元素（不傳入 `initialValue` 時）。

**功能**
從 5 位學生的資料陣列中，找出分數最高的學生並顯示姓名、分數與班級。

**測試結果**
```js
const students = [
  { name: '小明', score: 85, class: 'A' },
  { name: '小華', score: 92, class: 'B' },
  { name: '小美', score: 78, class: 'A' },
  { name: '小強', score: 95, class: 'B' },
  { name: '小莉', score: 88, class: 'A' },
];
```
| 項目 | 結果 |
|------|------|
| 最高分學生 | 小強 |
| 分數 | 95 |
| 班級 | B |

## 10 — 綜合挑戰：購物車動態結帳模擬 (Shopping Cart Checkout)

**語法重點**
```js
// 小計 = price * qty
// 折扣金額 = 小計 * (discount / 100)
// 稅金 = (小計總和 - 折扣總和) * 0.05
// 總額 = 小計總和 - 折扣總和 + 稅金
```
- `cart.push({ name, price, qty, discount })` 新增商品至購物車陣列。
- `cart.splice(index, 1)` 移除指定商品。
- `item.price.toFixed(2)` 格式化金額至小數點兩位。
- `renderCart()` 使用 `map()` 產生表格 HTML，即時更新統計面板。

**功能**
完整購物車模擬，包含：
1. **新增商品**：輸入名稱、單價、數量、折扣百分比
2. **動態列表**：表格顯示每項商品的小計金額，附刪除按鈕
3. **即時統計**：商品種類數、折扣總額、稅金 (5%)、應付總額
4. **結帳**：顯示完整明細並清空購物車
5. **清空**：一鍵重置

**測試結果**
| 操作 | 輸入 | 預期輸出 |
|------|------|----------|
| 新增商品A | $100 × 2, 折扣 10% | 小計 $180 |
| 新增商品B | $50 × 3, 折扣 0% | 小計 $150 |
| 統計面板 | — | 種類: 2, 折扣: $20, 稅金: $15.50, 總額: $325.50 |
| 結帳 | — | 小計: $350, 折扣: -$20, 稅金: $16.50, 總額: $346.50 |
| 移除商品A | — | 僅剩商品B, 總額: $157.50 |
