# 作業 04 — JavaScript 十項練習

一個互動式網頁，包含以下 10 個 JavaScript 練習：

| # | 主題 | 說明 |
|---|------|------|
| 01 | **判斷奇偶** | 輸入數字，判斷奇數或偶數 |
| 02 | **陣列求和** | 輸入逗號分隔數字，計算總和 |
| 03 | **尋找大於目標的最小 2 次方** | 給定 n，找出 2^k > n 的最小 k |
| 04 | **物件屬性讀取** | 透過點記法與括號記法讀取物件屬性 |
| 05 | **JSON 解析與字串化** | 示範 `JSON.parse()` 與 `JSON.stringify()` |
| 06 | **陣列過濾** | 設定閾值，用 `filter()` 篩選陣列 |
| 07 | **字母頻率統計** | 統計字串中各字元出現次數並顯示長條圖 |
| 08 | **陣列反轉 (手動演算法)** | 使用雙指針原地演算法反轉陣列 |
| 09 | **JSON 物件陣列尋找最高分** | 從學生資料陣列中用 `reduce()` 找出最高分 |
| 10 | **綜合挑戰：購物車結帳模擬** | 模擬購物車的新增/移除、折扣計算、稅金與結帳流程 |

## 使用方式

直接在瀏覽器中開啟 `js-learning.html` 即可操作各項練習。
